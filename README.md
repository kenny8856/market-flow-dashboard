# 台股個股關鍵地緣券商自動建庫與每週同步系統 (TW-Stock Geo-Broker Tracking System)

本專案利用**臺灣證券交易所 (TWSE)** 與 **證券櫃檯買賣中心 (TPEx)** 官方 OpenAPI 公開數據，自動建立台股全市場（上市 + 上櫃）個股與全台證券商營業分點的「地緣券商關係矩陣資料庫」，並支援每週自動同步更新與終端查詢。

---

## 一、官方三大交易所資料定位說明

| 機構 | 是否有地緣券商資料？ | 官方公開之底層數據 | 在本系統的定位 |
| :--- | :---: | :--- | :--- |
| **臺灣證券交易所 (TWSE)** | ❌ 無現成標籤 | 1. 上市公司基本資料（中文地址、產業、成立日）<br>2. 全台證券商分公司名冊（816+ 營業地址與電話）<br>3. 全台證券商總公司名冊（64+ 總部地址） | **核心資料源**（透過 OpenAPI 免費直連獲取） |
| **證券櫃檯買賣中心 (TPEx)** | ❌ 無現成標籤 | 上櫃公司基本資料（登記地址、統一編號、電話） | **核心資料源**（補足上櫃個股資料） |
| **臺灣期貨交易所 (TAIFEX)** | ❌ 無現成標籤 | 臺指期、個股期貨之口數與期貨商明細 | 僅涉及衍生性商品，與現貨股票分點無關 |

> **核心原理說明**：
> 官方主管機關不會直接標註誰是「地緣券商」（因地緣券商屬市場籌碼分析模型），但官方公開了**「上市櫃公司總部所在地」**與**「證券商分公司營業處所」**。透過地理空間與行政區解析比對（Geo-Proximity Mapping），即可精準計算出每檔股票的地緣券商清單！

## 二、地緣判定等級標準

1. **Level 1（核心地緣券商）**：
   - **同科學園區/科技重鎮**：如台積電（竹科）與新竹、竹科、竹北之專屬分點；大立光（南屯）與南屯在地分點。
   - **分點冠名在地**：分點名稱直接冠有公司所在行政區（例如：鴻海位於新北市土城區，對應「統一-土城」、「元大-土城永寧」、「凱基-土城」等）。
   - **同行政區**：公司與分點在同一鄉鎮市區（如台北市內湖區、台南市新市區）。
2. **Level 2（生活圈近鄰地緣）**：
   - 同縣市生活圈之其他分點營業處所（例如同在台南市、台中市或高雄市）。

## 四、資料庫結構 (SQLite)

- **`stocks`**：全市場上市櫃公司檔案（股票代號、名稱、市場別、產業、完整地址、縣市、行政區、園區）。
- **`broker_branches`**：全台 816+ 家證券商分點名冊（券商代號、名稱、營業地址、縣市、行政區、電話）。
- **`stock_geo_brokers`**：核心關聯表（股票代號、券商代號、分點名稱、地緣等級、判定理由、雙方地址）。
- **`sync_logs`**：每週同步紀錄表（同步時間、公司數、分點數、匹配關聯數、耗時秒數）。

## 六、上市與上櫃獨立歷史資料庫架構 (360 天落地)

本系統依交易所架構分為兩個獨立的 SQLite 市場資料庫：
- **上市資料庫**：`db/twse_market.db`
- **上櫃資料庫**：`db/tpex_market.db`

### 1. 每日個股行情表 (`daily_quotes`)
包含：日期、代號、名稱、開盤價、最高價、最低價、收盤價、漲跌價差、成交股數、成交張數、成交金額、成交筆數。

### 2. 每日三大法人明細表 (`daily_institutional`)
包含：日期、代號、名稱、外資及陸資買賣超(股/張)、投信買賣超(股/張)、自營商(自行買賣+避險)買賣超(股/張)、三大法人合計買賣超(股/張)。

### 3. 嚴格冪等防呆機制 (Delete-Then-Insert)
針對同日多次執行的防呆要求：在寫入任何日期前，一律以資料庫事務先執行 `DELETE WHERE date = ?`，再精準寫入最新盤後定案資料，完全保證**同日重複執行不會重複累加，舊資料自動被替換更新**。

## 七、日常一鍵更新（具備「智慧斷差自動補齊」與「假日防呆」）

每天盤後證交所與櫃買中心公布資料後（約 17:00 後），您只需執行一鍵更新。系統已升級**智慧斷差偵測引擎**：

### 核心智慧特性：
1. **自動偵測資料庫最新日期**：執行前先查詢資料庫最新落盤日期（例如週五），與今日日期計算時間差。
2. **自動補齊中間所有開盤工作日**：如果您因休假、出差、連假（如春節、中秋）或週末多日未執行，系統會**自動計算出這段期間所有缺漏的開盤交易日**，並自動依序全部補齊落庫！
3. **例假日自動防呆**：若在週六、週日執行，系統自動判斷為休市日，不會發送多餘請求，直接回報資料庫已收錄至最近一個交易日。
4. **同日重複執行嚴格去重**：當天多次執行時，以「先刪後存」機制自動刷新為最新盤後定案數據。

### 執行方式：
- **方法 1：雙擊執行檔（最推薦）**
  在 `D:\TW_Stock\` 資料夾中，直接雙擊 **`run_daily_task.bat`**。
- **方法 2：命令列執行**
  ```bash
  python daily_sync.py
  ```
- **方法 3：手動指定特定某天補抓**
  ```bash
  python daily_sync.py --date 2026-09-16
  ```

## 八、過去 360 天歷史全量回溯同步 (`sync_360_days.py`)

若要初始化建立過去一整年（360 天，約 245 個實際交易日）的所有個股收盤價與三大法人明細：

```bash
python sync_360_days.py --days 360 --market ALL
```

### 核心功能特點：
- **斷點續傳機制**：系統會自動記錄已同步之交易日。若中途中斷（如關閉電腦或網路斷線），下次執行會**自動從未完成的日期繼續**，無須從頭重跑。
- **保護官方連線**：內建每筆請求間隔延遲（預設 1.5 秒），避免觸發證交所/櫃買中心的連線頻率限制。

## 十、每週地緣券商排程設定（Windows 工作排程器）

公司偶有遷址，證券商亦會增設、整併分點。本系統提供 `weekly_sync.py` 與 `run_weekly_task.bat`，可自動拉取官方最新資料並重構矩陣。

### 設定排程步驟：
1. 按下鍵盤 `Win + R`，輸入 `taskschd.msc` 開啟「工作排程器」。
2. 點選右側「**建立基本工作**」。
3. **名稱**：輸入 `TW_Stock_GeoBroker_WeeklySync`。
4. **觸發程序**：選擇「**每週**」，建議設定在**每週日 20:00** 執行。
5. **動作**：選擇「**啟動程式**」。
6. **程式或指令碼**：瀏覽並選擇 `D:\TW_Stock\run_weekly_task.bat`。
7. **開始位置（選填）**：填入 `D:\TW_Stock\`。
8. 點選「完成」即設定完畢！系統每週將自動背景執行更新。

## 十一、權證資料庫與個股關聯系統 (`query_warrants.py`)

本模組對接臺灣證券交易所與櫃買中心官方 OpenAPI，獲取上市與上櫃全市場權證最新交易資料，並透過中文分詞與個股名稱對照表（1,986 檔上市櫃個股），將每檔權證自動鏈結至標的個股。

### 1. 官方 OpenAPI 端點與 Header 配置
- **上市權證端點 (TWSE)**：
  `https://openapi.twse.com.tw/v1/opendata/t187ap42_L`
- **上櫃權證端點 (TPEx)**：
  `https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap42_O`
- **嚴格遵循官方 HTTP 請求標頭**：
  - `accept: application/json`
  - `If-Modified-Since: Mon, 26 Jul 1997 05:00:00 GMT`
  - `Cache-Control: no-cache`
  - `Pragma: no-cache`

### 2. 個股名稱智慧關聯與欄位擴充 (+2 欄)
官方原始 JSON 輸出欄位為 `['出表/交易日期', '權證代號', '權證名稱', '成交金額', '成交張數/數量']`。
系統核心關聯引擎（`WarrantLinker`）會解析權證名稱（例如 `台積電永豐6C購02`、`前鼎凱基67購01`、`jpp統一6A購01`、`長科*凱基61購01`），自動辨識發行券商與期數，精準比對至底層個股，並在原 JSON 格式旁擴充兩欄：
- **`個股代號`**（如 `2330`、`4908`）
- **`個股名稱`**（如 `台積電`、`前鼎`）

### 3. 上市與上櫃分開建庫落地（近一年全量歷史數據）
- **上市權證資料庫**：
  - 本地路徑：`db/twse_market.db`
  - 資料表名稱：`daily_warrants`
  - 收錄範圍：`2024-05-10 ~ 2026-09-16`（共 **239 個開盤交易日**，完整一整年）
  - 總收錄筆數：**3,236,201 筆 (323.6 萬筆)**
  - 成功鏈結個股：**2,873,909 筆 (88.8%)**，涵蓋 503 檔上市標的個股
- **上櫃權證資料庫**：
  - 本地路徑：`db/tpex_market.db`
  - 資料表名稱：`daily_warrants`
  - 收錄範圍：`2025-09-22 ~ 2026-09-16`（共 **253 個開盤交易日**，完整一整年）
  - 總收錄筆數：**2,631,453 筆 (263.1 萬筆)**
  - 成功鏈結個股：**2,456,630 筆 (93.4%)**，涵蓋 296 檔上櫃標的個股
- **全市場合計**：**5,867,654 筆 (586.7 萬筆)**，嚴格具備 `(date, warrant_id)` 主鍵與 `(underlying_stock_id, date)` 索引，支援高速多日歷史查詢與先刪後存冪等更新。

### 4. 終端查詢工具使用指南 (`query_warrants.py`)
```bash
# 1. 檢視全市場權證資料庫落地儲存狀態與統計
python query_warrants.py --stats

# 2. 查詢台積電 (2330) 近 15 天或近一年 (360 天) 歷史權證多空趨勢 (認購/認售金額與比率)
python query_warrants.py 2330 --days 15
python query_warrants.py 2330 --days 360

# 3. 查詢上櫃前鼎 (4908) 近一年歷史權證走勢
python query_warrants.py 4908 --days 360

# 4. 查詢單日最新明細並導出附加【個股代號】與【個股名稱】之 JSON 格式
python query_warrants.py 2330 --export-json tsmc_warrants.json

# 5. 導出為 CSV 報表
python query_warrants.py 2330 --export-csv tsmc_warrants.csv
```

### 5. 整合至每日盤後一鍵更新
每天收盤執行 `python daily_sync.py` 或雙擊 `run_daily_task.bat` 時，系統會**自動同步個股行情、三大法人明細與最新權證交易資料**，一次性更新全市場數據！

## 八、臺灣期貨交易所 (TAIFEX) 全市場期貨與個股期大額交易人未沖銷部位結構資料庫

本模組對接臺灣期貨交易所官方數據，完整收錄**全市場所有期貨契約（包含指數期貨、商品期貨、匯率期貨以及全市場 300+ 檔個股期貨如台積電、聯電、鴻海、聯發科等，共 349 種商品）**之大額交易人（前五大、前十大合計）與特定法人未平倉籌碼，並自動按官方定義推算「遠月契約」（所有契約 - 當月契約）。

### 1. 資料庫規格 (`db/taifex_large_trader.db`)
- **資料表**：`futures_large_traders`
- **收錄範圍**：`2025-09-22 ~ 2026-09-21`（完整一整年 246 個交易日，全市場共 **246,011 筆**契約明細）
- **商品涵蓋**：**349 種期貨契約**
  - **指數與指數期貨**：臺股期貨 (TX)、小型臺指 (MTX)、微型臺指 (TMF)、電子期貨 (TE)、小型電子 (ZEF)、金融期貨 (TF)、小型金融 (ZFF)、富櫃200、半導體30等
  - **個股期貨**：全市場所有上市櫃股票期貨（台積電 CD、鴻海 DH、聯發科 DV、聯電 CC、長榮 CZ、中砂 EO 等共 300+ 檔標的）
  - **匯率與商品期貨**：小型美元兌人民幣、黃金期貨、原油期貨等
- **契約類型**：
  - **`當月契約`**（近月合約）
  - **`所有契約`**（市場全月份合計）
  - **`遠月契約`**（依公式自動運算：**遠月 = 所有契約 - 當月**）
  - **`週契約`**（週到期合約，如臺指週契約）
- **儲存欄位**：
  - 買方：前五大合計、前五大特定法人、前十大合計、前十大特定法人
  - 賣方：前五大合計、前五大特定法人、前十大合計、前十大特定法人
  - 全市場未平倉口數 (OI)
  - 衍生指標：前五大淨部位 (買-賣)、前五大特定法人淨部位、前十大淨部位 (買-賣)、前十大特定法人淨部位

### 2. 終端查詢工具指南 (`query_taifex_trader.py`)
系統支援透過**中文商品簡稱**（如 `台積電`、`鴻海`、`聯電`、`小台`）或**期交所契約代號**（如 `CD`、`DH`、`TX`、`MTX`）進行快速查詢：

```bash
# 1. 檢視大額交易人資料庫收錄狀態與統計
python query_taifex_trader.py --stats

# 2. 列出資料庫中所有收錄的 349 種期貨商品、總筆數與最新收錄日期
python query_taifex_trader.py --list

# 3. 查詢台積電個股期貨 (CD) 最近 5 天籌碼 (包含當月、遠月、所有契約)
python query_taifex_trader.py 台積電 --days 5

# 4. 查詢鴻海期貨 (DH) 最近 5 天籌碼
python query_taifex_trader.py 鴻海 --days 5

# 5. 查詢臺股期貨 (TX) 最近 5 天籌碼
python query_taifex_trader.py TX --days 5

# 6. 僅查看臺股期貨的「遠月契約」籌碼動向
python query_taifex_trader.py TX --type 遠月 --days 10

# 7. 匯出查詢結果至 CSV
python query_taifex_trader.py 台積電 --days 30 --export
```

### 3. 一鍵同步與排程更新
- **同步過去一整年歷史 (全市場 349 檔期貨)**：
  ```bash
  python sync_taifex_history.py
  ```
- **每日盤後增量更新（近 7 天）**：
  ```bash
  python sync_taifex_history.py --daily
  ```
- **Windows 一鍵批次檔執行**：
  直接雙擊 `run_sync_taifex.bat`，提供互動式選單：
  - [1] 日常盤後增量更新 (近 7 天)
  - [2] 回補近一年歷史資料庫 (全市場期貨+個股期)
  - [3] 查詢臺股期貨 (TX) 最新籌碼
  - [4] 查詢台積電期貨 (CD) 最新籌碼
  - [5] 查詢鴻海期貨 (DH) 最新籌碼
  - [6] 檢視全市場 349 種商品清單與統計
  - [7] 自訂查詢任一期貨商品或個股期

## 九、臺灣可轉換公司債 (CB) 市場行情與發行資料庫

本模組每日自臺灣證券櫃檯買賣中心 (TPEx) 官方取得全市場流通與掛牌之可轉換公司債交易行情與發行看板數據，並建置獨立專用資料庫 `db/cb_market.db`，完整收錄近一年（365 天）所有開盤交易日之全市場明細。

### 1. 核心欄位與指標設計
資料庫嚴格納入投資人研究可轉債所需之全套指標：
- **標的與代碼**：`cb_id`（可轉債代號）、`cb_name`（可轉債簡稱）、`underlying_id`（標的股票代號）、`underlying_name`（標的股票名稱）
- **每日價量行情**：`open_price`（開盤價）、`high_price`（最高價）、`low_price`（最低價）、`close_price`（收盤價）、`reference_price`（轉債官方參考價）、`volume_lots`（成交張數）、`trade_amount`（成交金額）
- **股債聯動與溢價指標**：
  - `conversion_price`：最新轉換價格（元）
  - `underlying_close_price`：標的股票當日收盤價格（元）
  - `conversion_value`：**轉換價值** $= \frac{\text{標的股票現價}}{\text{轉換價格}} \times 100$
  - `premium_rate`：**折溢價率(%)** $= \frac{\text{CB價格} - \text{轉換價值}}{\text{轉換價值}} \times 100\%$（優先採用當日收盤成交價；若無成交則採官方參考價運算）
- **發行與籌碼指標**：
  - `issue_lots`：原始發行總張數（原始發行總額 / 10 萬元）
  - `outstanding_lots`：最新流通在外剩餘張數（上月底發行餘額 / 10 萬元）
  - `listing_date`：上市/上櫃掛牌日期
  - `maturity_date`：到期日 / 轉換迄日

### 2. 資料庫規格 (`db/cb_market.db`)
- **主要資料表**：
  - `daily_cb_quotes`：每日可轉債行情與指標明細（以 `(date, cb_id)` 為主鍵，具備 `date`、`cb_id` 與 `underlying_id` 高效索引）
  - `cb_basic_info`：可轉債基本資料母表
  - `sync_progress`：同步進度追蹤表（具備斷點續傳機制）
- **歷史數據量**：完整收錄近一年 240+ 個交易日、約 8~9 萬筆歷史明細。

### 3. 終端查詢工具 (`query_cb.py`)
```bash
# 1. 查詢最新一日全市場成交量排行前 25 大可轉債
python query_cb.py --sort volume --limit 25

# 2. 篩選低溢價或折價可轉債 (溢價率 <= 10%)
python query_cb.py --undervalued --limit 25

# 3. 查詢指定日期 (如 2026-09-17) 行情
python query_cb.py --date 2026-09-17

# 4. 查詢特定可轉債 (如中砂二 15602) 近期歷史走勢與溢價率
python query_cb.py --cb 15602

# 5. 查詢特定股票 (如中砂 1560、聯電 2303) 所發行之全部可轉債現況
python query_cb.py --stock 1560
python query_cb.py --stock 2303
```

### 4. 每日更新與歷史回補 (`sync_cb_history.py` / `run_sync_cb.bat`)
- **回補過去一年歷史**：
  ```bash
  python sync_cb_history.py --days 365
  ```
- **日常增量更新（近 7 天）**：
  ```bash
  python sync_cb_history.py --days 7
  ```
- **Windows 一鍵執行**：
  直接雙擊 `run_sync_cb.bat`，即可選單執行日常更新、歷史回補或即時行情查詢。

## 十、臺灣證交所 (TWSE) 與櫃買中心 (TPEx) 全市場個股借券 (SBL) 資料庫

本模組對接臺灣證券交易所借券中心與證券櫃檯買賣中心官方數據，完整收錄全市場上市與上櫃所有個股之**「借券餘額」**（總借入量、還券量、未還存量、借券市值）與**「借券賣出及融券餘額」**（當日放空賣出、借券賣出餘額、融券餘額），並自動推算**「借券賣出使用率」**（$\frac{\text{借券賣出餘額}}{\text{借券總餘額}} \times 100\%$）。

### 1. 資料庫規格 (`db/stock_sbl.db`)
- **資料表結構**：
  - `daily_sbl_balance`：全市場每日借券餘額明細（對接 TWSE 跨市場借券中心 `TWT72U`，同時涵蓋上市與上櫃）
  - `daily_sbl_short`：全市場每日借券賣出與融券餘額明細（上市對接 TWSE `TWT93U`，上櫃對接 TPEx `margin_sbl`）
  - `v_stock_sbl_all`：全市場借券與放空整合查詢視圖
  - `sync_progress`：同步進度追蹤與斷點續傳紀錄
- **收錄時間範圍**：`2025-09-15` 至今（約 247 個開盤交易日，50+ 萬筆全市場明細）
- **涵蓋標的**：全市場上市櫃 2,240+ 檔股票

### 2. 核心欄位說明
- **借券借入 (SBL Borrow)**：當日向借券中心或券商借入之總數量（股/張）
- **借券還券 (SBL Return)**：當日歸還了結之借券數量（股/張）
- **借券總餘額 (SBL Total Balance)**：目前累積借入尚未返還之總存量（股/張）
- **當日借券賣出 (SBL Short Sell)**：當日將借來之股票在市場上放空賣出之數量（股/張）
- **借券賣出還券 (SBL Short Return)**：當日還券之借券賣出數量（股/張）
- **借券賣出餘額 (SBL Short Balance)**：目前已在市場上放空賣出但尚未回補還券之存量（股/張）
- **借券賣出使用率 (%)**：$\frac{\text{借券賣出餘額}}{\text{借券總餘額}} \times 100\%$，數值愈高代表借來的股票大部分都已經拿去市場放空！
- **融券餘額 (Margin Short Balance)**：一般信用交易融券放空存量（張）

### 3. 終端查詢工具指南 (`query_sbl.py`)

```bash
python query_sbl.py 鴻海 --days 15
python query_sbl.py 元太 --days 15

# 3. 查詢最新一日全市場【借券賣出餘額 (放空存量)】前 20 大排行
python query_sbl.py --top-short --limit 20

# 4. 查詢最新一日全市場【借券總餘額】前 20 大排行
python query_sbl.py --top-borrow --limit 20

# 5. 查詢最新一日全市場【當日借券賣出量 (當日放空力道)】前 20 大排行
python query_sbl.py --top-sell --limit 20

# 6. 匯出個股借券歷史數據至 CSV
python query_sbl.py 2330 --days 60 --export

# 7. 檢視資料庫收錄狀態與統計

```

## 十一、臺灣證交所 (TWSE) 與櫃買中心 (TPEx) 全市場個股融資融券 (信用交易) 資料庫

本模組對接臺灣證券交易所官方 `MI_MARGN` 與證券櫃檯買賣中心官方 `margin_balance` 數據，完整收錄全市場上市與上櫃所有個股之**每日融資買進/賣出/現償/餘額**、**融券買進/賣出/券償/餘額**與**資券互抵**，並自動推算**「融資增減」**、**「融券增減」**與市場最具指標性的**「券資比 (%)」**（軋空強度指標）。

### 1. 資料庫規格 (`db/margin_trading.db`)
- **資料表結構**：
  - `daily_margin_trading`：全市場每日個股融資融券明細（單位：張，主鍵 `(date, stock_id)`）
  - `sync_progress`：同步進度追蹤與斷點續傳紀錄
- **收錄時間範圍**：`2025-09-15` 至今（約 247 個開盤交易日，50+ 萬筆全市場明細）
- **涵蓋標的**：全市場上市櫃 2,240+ 檔股票

### 2. 核心指標與公式
- **融資買進/賣出/現償/餘額 (張)**：散戶與主力槓桿買進之每日動態與存量
- **融券買進/賣出/券償/餘額 (張)**：信用融券放空、回補與未平倉存量
- **融資當日增減 (張)**：$\text{今日融資餘額} - \text{前日融資餘額}$
- **融券當日增減 (張)**：$\text{今日融券餘額} - \text{前日融券餘額}$
- **券資比 (%)**：$\frac{\text{今日融券餘額}}{\text{今日融資餘額}} \times 100\%$（台股評估「軋空力道」之黃金指標）
- **資券互抵 (張)**：當日沖銷信用融資買進並融券賣出互抵沖銷之張數

## 十二、官方資料發布時程防呆機制、出差智慧接續與一鍵總同步大師系統

為解決投資人經常出差導致資料庫出現時間斷層，以及盤後過早執行可能抓取到尚未公布空資料的問題，本專案全面導入**「時程防呆檢驗機制」**與**「出差智慧接續補齊功能 (Smart Catch-up)」**。

### 1. 官方資料庫盤後發布時程與防呆規則表

| 資料庫 / 模組項目 | 官方主要來源端點 | 每日官方公布門檻 | 時間防呆行為與保護規則 |
| :--- | :--- | :---: | :--- |
| **1. 臺股收盤行情與三大法人** | TWSE `MI_INDEX`, `T86`<br>TPEx `daily_close_quotes`, `fund_summary` | **平日 15:30** | 收盤 13:30，三大法人與盤後定價約 15:00~15:30 彙整完畢。<br>**若當前時間未達 15:30，系統自動排除今日，終點設為前一營業日**。 |
| **2. 期交所期貨大額交易人** | TAIFEX `largeTraderFutQry` | **平日 15:30** | 每日約 15:00~15:30 期交所公布部位結構表。<br>**未達 15:30 自動排除今日**。 |

### 2. 出差無痛「智慧接續補齊 (Smart Catch-up)」

所有同步程式均配備 `--catchup` 參數：
- **自動偵測進度**：自動查詢資料庫中最後收錄的開盤日（如 `2026-08-15`）。
- **無縫自動計算**：精確算出出差期間所有開盤交易日（自動排除例假日與國定假日）。
- **秒速比對**：已收錄完整的交易日以 `0.001s` 快速跳過，僅針對缺漏日期發送請求。
- **最新狀態秒回**：若資料庫已是最新狀態，程式會在 `0.2 秒` 內主動提示「已是最新狀態，無需同步」並正常結束，絕不觸發伺服器頻率管制。

## 十三、大盤多空溫度計與實戰策略選股器 (離線現代化網頁儀表板系統)

為提供直覺、全面且具備實戰指導性的決策介面，系統已內建**「100% 純自給自足、無外部網路依賴」**的現代化離線網頁儀表板 (dashboard.html)。

### 1. 核心設計與特色
1. **100% 離線純自給自足 (Zero CDN Dependency)**：
   - 無需安裝 Node.js 或前端框架，無需網路連線（即使在飛機或斷網環境亦可正常運作）。
   - 不依賴任何外部 CDN（如 Bootstrap、Tailwind、Chart.js、Google Fonts），所有視覺樣式採用原生深色高對比金融配色，圖表全部使用純原生 **HTML5 Canvas 2D API** 獨立渲染。
2. **大盤立體多空溫度計 (Market Regime Radar)**：
   - 跨 5 大資料庫即時運算 5 大籌碼面向加權評分（0 ~ 100 分）：
     - **期交所期貨特法籌碼 (25%)**：臺指期 (TX) 所有契約前十大特法淨未沖銷部位與日變化。
     - **現貨三大法人動能 (25%)**：外資與投信當日及 5 日累計買賣超金額與集中度。
     - **散戶融資籌碼沉澱 (20%)**：融資餘額增減與散戶追高/停損多殺多訊號。
     - **外資借券賣出放空壓力 (15%)**：全市場借券賣出存量變化與當日借賣動能。
     - **可轉債市場熱度與保底 (15%)**：全市場可轉債中位數溢價率與百元以下折價債比重。
   - 動態指針儀表盤 (Gauge Meter) 與近 30 個交易日多空走勢圖 (Trend Chart)。
   - **實戰持股水位建議**：明確給出目前該激進、保守或空手（如：持股水位 30% ~ 50%）。
3. **四大實戰策略選股器 (Tactical Stock Screener)**：
   - **黃金軋空股 (Short Squeeze)**：券資比 > 30% 且融券持續攀升，融券被軋的高爆發標的。
   - **高檔出貨預警股 (Distribution Alert)**：借券賣出激增 + 投信外資撤退 + 融資套牢之高危險股。
   - **可轉債保底安全牌 (CB Safety Moat)**：價格在 100~115 元附近且折溢價率極低，進可攻退可守。
   - **個股期主力重押股 (Single-Stock Futures)**：前十大特法在個股期貨大舉買進未平倉，潛在強攻波段標的。
4. **前端即時互動功能**：

   - 支援各欄位（收盤價、漲跌幅、券資比、借券賣出、成交量等）**點擊表頭正反向排序**。

## 十六、臺灣期交所 (TAIFEX) 選擇權全鏈資料庫與 TDCC 集保千張大戶股權分散系統

為完美銜接機構級「全市場資金流向與部位地圖」之分析深度，系統全面擴建 2 大核心資料庫與 1 組產業類股資金輪動模組：

### 1. 期交所選擇權市場資料庫 (`db/taifex_options.db`)
- **歷史收錄時間**：自 **`2025-09-15` 至今 (249 個交易日，全量覆蓋無缺漏)**。
- **四大核心數據表**：
  1. `txo_pc_ratio`：每日臺指選擇權成交量與未平倉 **Put/Call Ratio (P/C比率)**。
  2. `txo_strike_quotes`：每日全市場各到期月/週別、各履約價之開高低收、結算價與未平倉契約數 (OI，累積 60+ 萬筆)。
  3. `txo_institutional`：外資、投信、自營商三大法人 CALL / PUT 買賣方交易金額與未平倉淨額。
  4. `txo_large_trader`：前五大、前十大特法選擇權未平倉部位。
- **獨家量化指標運算**：
  - **Max Pain (最大痛點)**：使選擇權莊家賣方賠付金額最小之結算點位。
  - **支撐壓力牆 (OI Walls)**：Call 最大未平倉履約價（天花板壓力牆）與 Put 最大未平倉履約價（地板支撐牆）。
- **終端查詢工具 (`query_options.py`)**：
  ```bash
  # 1. 試算最新一日 Max Pain (最大痛點) 與支撐壓力牆
  python query_options.py --max-pain

  # 2. 檢視近 15 天 Put/Call Ratio 走勢與多空傾向
  python query_options.py --pc-ratio --days 15

  # 3. 查詢最新三大法人選擇權契約金額與多空部位
  python query_options.py --institutional

  # 4. 檢視選擇權資料庫狀態統計
  python query_options.py --stats
  ```

---

### 2. 臺灣集中保管結算所 (TDCC) 集保戶股權分散表資料庫 (`db/stock_tdcc.db`)
- **收錄對象**：全市場 2,000+ 檔上市櫃股票，每週五定時同步。
- **核心指標運算**：
  - **千張大戶持股比率 (>1,000張)**：外資、董監與主力核心底倉集中度。
  - **400張以上大戶比率 (>400張)**：實質波段主力控盤水位。
  - **散戶持股比率 (<10張 / <50張)**：零股與散戶接刀或退場籌碼沈澱指標。
  - **總股東人數變化**：股東人數激增常伴隨籌碼凌亂，人數下降代表籌碼沉澱。
- **終端查詢工具 (`query_tdcc.py`)**：
  ```bash
  # 1. 查詢單檔個股 (如台積電 2330) 股權集中度與近 8 週趨勢
  python query_tdcc.py 2330

  # 2. 查詢鴻海 (2317) 或聯發科 (2454)
  python query_tdcc.py 2317
  python query_tdcc.py 2454

  # 3. 全市場千張大戶持股比率最高 TOP 25 排行榜 (主力鎖碼股)
  python query_tdcc.py --top-big --limit 25

  # 4. 檢視集保資料庫收錄狀態
  python query_tdcc.py --stats
  ```

---

### 3. 全市場產業類股資金流向與族群輪動分析 (`query_sector_flow.py`)
- **原理**：結合 `twse_market.db`、`tpex_market.db` 與 `stock_geography.db` 產業分類，即時運算全市場 34 大產業類別之資金成交比重與法人進出。
- **指標功能**：
  - 各產業每日成交金額與佔大盤比重（快速捕捉佔比 > 35% 之重押集中板塊，或由 5% 擴大至 15% 之熱門輪動板塊）。
  - 外資與投信在各族群的買賣超金額推估。
- **終端查詢**：
  ```bash
  # 查詢最新一日全市場產業資金流向排行
  python query_sector_flow.py

  # 查詢特定日期 (如 2026-09-22)
  python query_sector_flow.py --date 2026-09-22 --top 20
  ```
